SQL JOIN Query Practice – World Database

This repository contains SQL JOIN query practice using the World database.
It is created to strengthen understanding of relational databases and different types of SQL JOIN operations through hands-on queries.

Files in this Repository
1. world.sql

Contains the World sample database

Includes tables like country, city, and countrylanguage

Used as the base database for all SQL queries

2. practise.sql

Contains my practice SQL queries

Covers:

INNER JOIN

LEFT JOIN

RIGHT JOIN

Multiple table JOINs

Written for learning and revision purposes

How to Use

Import world.sql into your SQL environment (MySQL / MariaDB).

Run the queries from practise.sql.

Analyze the output to understand how JOINs work across tables.

Purpose

Improve SQL JOIN concepts

Practice real-world database queries

Helpful for beginners and data science learners
